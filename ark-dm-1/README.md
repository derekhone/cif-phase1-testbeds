# ARK-DM-1

## Hidden-Inheritance Rotation Curve Test

ARK-DM-1 is a preregistered open-data experiment inspired by the former UIP / Ark / inheritance-field library.

The purpose is not to claim that Ark, UIP, or any new physics explains dark matter.

The purpose is narrower:

Can an inheritance-inspired hidden term be translated into a measurable mathematical model and tested against public galaxy rotation-curve data?

## Status

Preregistered before execution.

No code has been run yet under this test.

## Public Posture

This is a falsification attempt.

It is not a discovery claim.

It is not a claim that dark matter has been explained.

It is not a claim that the former UIP framework is established physics.

It is a test of whether an inheritance-inspired concept can be converted into a measurable model and compared honestly against public astrophysical data.

## Dataset

Planned dataset:

SPARC galaxy rotation-curve database.

The test is intended to use public galaxy rotation-curve data, including observed velocities and baryonic components where available.

No private data will be used.

## Model Families

The preregistered comparison includes:

1. Visible-matter-only baseline

A baseline prediction using baryonic matter contributions only.

2. Standard dark-matter halo baseline

A conventional halo-style model such as NFW, Burkert, or pseudo-isothermal, depending on what can be implemented cleanly and reproducibly from the public data.

3. Ark-inspired hidden-inheritance term

A simple mathematical correction term inspired by the former Ark / UIP language of hidden inheritance, residual influence, coherence support, and unseen burden.

The Ark-inspired term must be expressed in measurable mathematical form.

No mystical, symbolic, theological, or metaphorical language will be used as evidence inside the model.

## Preregistered Core Question

Can a hidden-inheritance correction term improve galaxy rotation-curve prediction over visible-matter-only baselines on a preregistered public dataset?

## Preregistered Kill-Condition

The Ark-inspired hidden-inheritance term FAILS if it does not reduce median prediction error by at least 10% compared with the visible-matter-only baseline on the preregistered sample.

The Ark-inspired term also FAILS as a novel candidate if it performs worse than, or only comparably to, a standard dark-matter halo model after accounting for model complexity.
