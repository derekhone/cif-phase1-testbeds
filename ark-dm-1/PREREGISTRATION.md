# ARK-DM-1 Preregistration

## Title

ARK-DM-1: A Preregistered Open-Data Test of Hidden-Inheritance Terms in Galaxy Rotation Curves

## Status

Preregistered before execution.

This test is inspired by the former UIP / Ark / inheritance-field library, but it does not claim that Ark, UIP, or any new physics explains dark matter.

The purpose is to test whether an Ark-inspired hidden-inheritance correction term can be translated into a measurable, falsifiable model and evaluated against public galaxy rotation-curve data.

## Core Question

Can a hidden-inheritance correction term improve galaxy rotation-curve prediction over visible-matter-only baselines on a preregistered public dataset?

## Dataset

Primary dataset: SPARC galaxy rotation-curve database.

The test will use publicly available galaxy rotation-curve data, including observed rotation velocities and baryonic components where available.

No private data will be used.

## Models To Compare

The test will compare at least three model families:

1. Visible-matter-only baseline

A baseline model using the observed baryonic contribution only.

2. Standard dark-matter halo baseline

A conventional halo-style model, such as NFW, Burkert, or pseudo-isothermal, depending on what is most practical and reproducible from the available data.

3. Ark-inspired hidden-inheritance term

A simple correction term inspired by the Ark / UIP library, translated into measurable mathematical form.

The Ark-inspired term may be based on one or more public observables such as:

- baryonic radial distribution
- disk scale length
- gas distribution
- observed residual structure
- radial acceleration residuals
- density-gradient or continuity-style terms

No mystical, symbolic, or theological language will be used inside the mathematical model.

## Hypothesis

A preregistered hidden-inheritance correction term will reduce prediction error compared with the visible-matter-only baseline across the selected SPARC sample.

## Kill-Condition

The Ark-inspired hidden-inheritance term FAILS if it does not reduce median prediction error by at least 10% compared with the visible-matter-only baseline on the preregistered sample.

The Ark-inspired term also FAILS as a novel candidate if it performs worse than, or only comparably to, a standard dark-matter halo model after accounting for model complexity.

## Success Conditions

The test is considered a limited PASS only if:

1. the Ark-inspired term improves median prediction error by at least 10% over the visible-matter-only baseline, and

2. the improvement is not dependent on hand-tuning individual galaxies after seeing results, and

3. the result is reproducible using the public code and selected public data.

A PASS does not prove dark matter, new physics, Ark, or UIP.

A PASS only means the Ark-inspired term survived this specific preregistered open-data test and may justify a narrower follow-up study.

## Failure Conditions

The test FAILS if:

- the Ark-inspired term does not beat visible-matter-only by the preregistered threshold,
- the result only works after post-hoc tuning,
- the result depends on excluding difficult galaxies after seeing outcomes,
- the term performs worse than standard halo baselines after complexity is considered,
- the code or data cannot reproduce the result.

## Interpretation Rules

No claim of new physics will be made from this test.

No claim that Ark or UIP explains dark matter will be made.

If the model fails, the failure will be published.

If the model partially improves prediction but loses to standard halo models, that will be reported as a limited or non-novel result.

If the model passes the preregistered threshold, it will be framed only as a candidate mathematical pattern requiring independent review.

## Planned Outputs

The planned outputs are:

- ARK-DM-1 code
- selected SPARC sample notes
- model comparison results
- error table
- pass/fail result
- final ARK-DM-1 results report
- GitHub publication
- optional Zenodo archive if the result is complete and worth preserving

## Public Posture

This is a falsification attempt inspired by the former UIP / Ark library.

It is not a claim of discovery.

It is not a claim that dark matter has been explained.

It is a test of whether an inheritance-inspired idea can be translated into a measurable model and evaluated honestly against public astrophysical data.

## Rule

Preregister first. Run once under the stated rules. Publish pass or fail.
