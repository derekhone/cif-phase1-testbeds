# ARK-DM-1 Data Source

## Primary Dataset

ARK-DM-1 is planned to use the SPARC galaxy rotation-curve database.

SPARC contains public galaxy rotation-curve data and baryonic component information used in astrophysical studies of galaxy dynamics, visible matter, and dark-matter halo modeling.

## Intended Data Use

The experiment will use public rotation-curve data to compare:

1. visible-matter-only prediction,
2. standard halo-style modeling where feasible,
3. an Ark-inspired hidden-inheritance correction term.

## Data Requirements

The selected galaxies should include sufficient information to compute or compare:

- radial distance values,
- observed rotation velocity,
- uncertainty where available,
- baryonic contribution or baryonic component terms,
- gas / disk / bulge components where available,
- enough radial points for a meaningful galaxy-level error estimate.

## Public Data Rule

No private data will be used.

No manually selected data will be added after seeing results.

If data cannot be parsed or required values are missing, the exclusion must be documented in the final results.

## Source Integrity Rule

Any local data file used for ARK-DM-1 must be listed in the final results with:

- file name,
- source URL or citation,
- download date,
- any preprocessing performed,
- any galaxies excluded and why.

## Interpretation Limit

Use of SPARC data does not imply endorsement by SPARC authors or by any external institution.

ARK-DM-1 is an independent open-data falsification attempt inspired by the former Ark / UIP library.
